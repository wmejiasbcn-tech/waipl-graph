# Skill — gestión de ventanas

Copia de registro. La skill operativa vive en el agente.

Graphy es la presentación. Lo que el visitante ve es **una** ventana.

1. Portada = Ecosistema Digital Inmersivo.
2. Mapa = universo de nodos.
3. Ficha / glosario / HUD = capas, no otra presentación.
4. Nunca tapar Graphy con una lámina, un archivo o un overlay temporal.
5. “Vuelve a poner la presentación” = se quita el overlay y queda la portada.
