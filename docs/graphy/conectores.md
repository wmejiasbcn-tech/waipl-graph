# Inventario de conectores — 12 de septiembre de 2026

Nada nace, nada se hace y nada funciona sin haber sido concebido previamente con el ADN del ecosistema.

Lo que está conectado. Lo que se puede. Lo que no.

## Presentación y diseño

| Conector | Puedo | No puedo / límite |
|---|---|---|
| **Gamma** | Buscar decks, plantillas, importar un HTML público | No genera un deck desde cero con un solo “hazme la presentación” si no hay plantilla o HTML. No sustituye a Graphy. |
| **Canva** | Combinar, reordenar, insertar o borrar páginas. Editar contenido de un diseño existente | Borrar páginas exige confirmación literal. No es Graphy. |
| **Excalidraw** | Dibujar un esquema a mano (nodos, flechas) | No es un mapa 3D. No publica solo. |
| **Figma** | Leer archivos, shaders, plugins generativos | No despliega Graphy. |
| **HyperFrames (HeyGen)** | Componer vídeo, listar proyectos, renderizar MP4 | El render es de pago. Importar HTML solo desde el canal de Claude Design. |
| **Wix** | Crear/publicar un sitio, subir imágenes, API del sitio | No es el mapa inmersivo. Hay que elegir el sitio; no se adivina. |

## Publicar al mundo

| Conector | Puedo | No puedo / límite |
|---|---|---|
| **Netlify** | Listar equipos y sitios, **desplegar un sitio** si hay `siteId` | No invento un sitio nuevo sin que lo confirmes. |
| **Vercel** | Comprar créditos, Pro, dominio | **No hay despliegue desde aquí.** Graphy no se publica por Vercel con estas herramientas. |
| **GitHub** | Repositorio, PR, merge, reglas | No sirve el mapa al visitante. Es el registro. |
