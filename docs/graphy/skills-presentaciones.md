# Skill — presentaciones

Copia de registro. La skill operativa vive en el agente.

Graphy es la experiencia inmersiva. Gamma y Canva son decks. Excalidraw es esquema. HyperFrames (HeyGen) es vídeo. Figma es diseño. Wix es sitio.

El texto del Soberano no se sintetiza. Una lámina (Paradigma de la Hibridación, ciudad cibernética) se guarda en identidad; no se pone de portada salvo orden expresa.
